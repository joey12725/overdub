# Licences — weapons and projectiles

Every model in `assets/models/weapons/` and `assets/models/projectiles/` is original work generated
by the scripts in `art/weapons/` (Blender Python, modelled by hand). No third-party meshes, textures
or fonts are included, and nothing was downloaded.

The concept sheets in `docs/reference/generated/weapons/` were made with the project image model
(`tools/img`, gpt-image-2.6-sunburst) using the project Moxie references as inputs. They are
reference only and are not shipped in the game.
