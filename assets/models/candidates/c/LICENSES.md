# Moxie candidate C - sources and licences

## Made for this project (no third-party content)
Everything in `moxie.glb` except the animation data: the mesh (head, eyes, hair, body, hands, clothing,
boots, headphones, Walkman, belt kit, wrist devices), the textures (`moxie_face`, `moxie_eyes`,
`moxie_pants` painted by `art/moxie_c/mc_paint.py`; `moxie_gear`, `moxie_jacket`, `moxie_shoes` palette
swatches), the humanoid skeleton `Rig`, the skin weights and the Rigify control rig in
`art/moxie_c/moxie.blend`. All of it is generated by the Python sources in `art/moxie_c/`.
