# assets/audio

Everything the game hears. Code: `audio/` (facade `res://audio/audio.tscn`, extends `AudioBase`).

| Folder | What | Made by |
|---|---|---|
| `inst/`, `drums/`, `blip/`, `sfx/`, `ui/`, `voice/count_*` | Generated sample families, listed in `manifest.json` | `python -I art/audio/make_samples.py [family ...]`, check with `art/audio/analyze.py` |
| `voice/elevenlabs/` | Recorded dialogue, barks, count-in words, deck calls, efforts; `manifest.json` | `art/voice_el/` (docs/VOICE-CAST.md). Do not regenerate casually: the ElevenLabs quota is unknown. |

Generated files: 16-bit PCM mono 44.1 kHz, `pad` (100 ms) of digital silence first (the voice engine
seeks into it to place attacks between mix boundaries), loudest member of a family at -1 dBFS, PCM
import (`compress/mode=0`). Rebuilding one family keeps the others byte-identical.

## Trap sounds (docs/TRAPS.md "Events for audio and fx")

| Event detail | Cue (`AudioSfx`) | Families | Pitch (chord at the accent) |
|---|---|---|---|
| `spikes:warn`, `crusher:warn`, `flame:warn` | `trapWarn`: tick one beat before the activation, tock half a beat later | `trap_tick` | root, then fifth, octave 5 |
| `spikes:up` / `spikes:down` | `spikesUp` / `spikesDown` | `spike_up` (+ tri blip) / `spike_down` | fifth / root |
| `crusher:slam` | `crusherSlam` (impact; louder per body struck) | `crusher_slam`, `break_tone` | root, two low octaves |
| `crusher:retract`, `:hold`, `:open` | | `crusher_retract`, `switch_click`, `plate_thunk` | |
| `conveyor:on/off/reverse/forward` | `conveyor` | `conveyor_clunk`; while running the loop `conveyor_hum` (tuned to the key root, `AudioTrapLoops`) | root |
| `flame:on` / `flame:off` | `flameOn` / `flameOff` | `flame_ignite` / `flame_out`; while burning the loop `flame_roar` | |
| `dart:fire`, `dart:on/off` | `dartFire`, `dartToggle` | `dart_fire`, `switch_click` | third |
| `bumper:fire` | `bumper` | `bumper_boing` | root, fifth |
| `sensor:on/off` | `sensor` | `sensor_beep` | third / root |
| `relay:armed`, `relay:on/off` | `relayArmed`, `relay` | `trap_tick`, `switch_click` | |
| `magnet:on/off` | `magnet` | `laser_on` / `laser_off` | root |

The hums sound only while the master transport runs and restart from the level's beat-zero state
on every take.

## Buses

`Master, Music, Reverb, Drums, Layer1-4, Send1-4, Sfx, SfxA-D, Ui, Voice` (`audio/audio_bus_setup.gd`;
`default_bus_layout.tres` is generated by `bash tools/gd script res://audio/tools/make_bus_layout.gd`).
Dialogue and barks play on `Voice`; the music ducks 6 dB under a line and 3 dB under a bark (80 ms
down, 400 ms back, 150 ms hold). Count-in words play on `Ui`, efforts on the acting tape's `SfxA..D`.

## Checks

- `bash tools/gd test audio` — unit and integration tests (`tests/audio/`).
- `bash tools/gd shot res://tools/audio_preview.gd` — plays the sandbox through the facade.
- `bash tools/gd shot res://tools/audio_mix_check.gd -- level=<id>` then
  `python -I art/audio/mix_check.py` — loudness per bus, master headroom, clipping, dialogue over music.
